# Fake News Detection Using NLP

A machine learning project that detects whether a news article is **Real or Fake** using Natural Language Processing (NLP) and text classification techniques.

## Overview
The system analyzes news headlines and article content, preprocesses the text and uses machine learning models to classify news articles.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- NLP
- TF-IDF Vectorization
- Matplotlib, Seaborn

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Support Vector Machine (SVM)

## Methodology
1. Dataset collection and exploration
2. Text preprocessing and cleaning
3. Feature extraction using TF-IDF
4. Model training and testing
5. Evaluation using Accuracy, Precision, Recall, and F1-score

## Results
The Support Vector Machine (SVM) model achieved the best performance among the evaluated models.
